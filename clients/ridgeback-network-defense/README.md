# Ridgeback Network Defense Operating System

This client area turns Ridgeback's Breach of Protocol workflow into reusable operating system parts:

- strategy that explains the point of view
- operations docs that guide weekly execution
- show docs that define editorial-first behavior
- episode folders that hold structured planning data
- automation contracts that keep the workbook and repo aligned

The intent is to reuse the same folder system for future clients with different positioning, hosts, and content pillars.
