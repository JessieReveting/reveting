# Ridgeback Asset Naming Conventions

Use this pattern for repeatable file discovery:

`ridgeback-breach-of-protocol_ep-<episode-number>_<asset-type>_<channel>.<ext>`

Examples:

- `ridgeback-breach-of-protocol_ep-056_event-copy_linkedin.md`
- `ridgeback-breach-of-protocol_ep-056_clip-plan_master.md`
- `ridgeback-breach-of-protocol_ep-057_recap_newsletter.md`
