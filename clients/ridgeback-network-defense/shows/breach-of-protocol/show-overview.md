# Breach of Protocol Show Overview

## Show Model

Breach of Protocol is an editorial-first livestream and content engine for Ridgeback Network Defense.

The approved strategic theme and episode brief come before guest-booking logic.

## Editorial Rule

Use cybersecurity news as evidence, but translate it into strategic public discussion topics that stay relevant even if the news cycle shifts.

The public discussion topics should usually answer:

1. What changed in the threat landscape this week?
2. What defensive blind spot does this reveal?
3. What should security leaders do differently now?

## Output Model

One live episode can become:

- one live event
- one event description
- one run of show
- one replay post
- one recap
- one article or newsletter
- five to eight clips
- three to five thought-leadership posts
- two to three company-page posts
- one poll
- one carousel or framework asset
- one quote graphic
- one YouTube upload
- one podcast upload
