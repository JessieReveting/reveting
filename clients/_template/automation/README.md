# Workbook Automation Template

This folder holds the structured inputs that workbook sync scripts should read.

Keep these files human-editable.

- `workbook-manifest.yaml`: workbook metadata and tab contract
- `workbook-content.yaml`: strategy and schedule rows that belong in the sheet
- `sheet-sync-plan.md`: how repo data and workbook data stay in sync
- `validation-rules.md`: checks the validator should enforce
