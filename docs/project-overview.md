# Project Overview

## What We Built

Reveting Operations Manager is a read-only AI operations manager for recurring Reveting shows.

It acts like an operations copilot for LinkedIn Live production, livestream production, podcast production operations, guest booking workflows, production calendar QA, and post-production readiness.

Instead of relying on people to manually compare HighLevel, Google Calendar, StreamYard, LinkedIn Events, Gmail, and Google Drive, the system pulls local snapshots together and explains what is happening in one place.

## Why It Matters

Reveting runs recurring shows with many operational steps:

- guest bookings
- forms and custom fields
- calendar creation and invite review
- livestream studio readiness
- LinkedIn event promotion
- reminder and SOP communications
- post-production assets and follow-up

When these are managed across multiple systems, small mismatches can create production risk. The project reduces that risk by surfacing what is missing, what is confirmed, and what still needs a human decision.

## How It Helps Reveting

It helps Reveting:

- see all supported shows in one operational system
- catch booking and calendar mismatches before they become show-day problems
- prioritize operator work with a Daily Operations Brief and work queue
- handle edge cases like PR representatives booking on behalf of guests
- track readiness for livestreams, podcasts, and LinkedIn Live episodes
- learn recurring operational patterns safely through Knowledge Mode

## What It Can Do Today

Today the system can:

- read HighLevel discovery outputs for bookings, forms, submissions, and custom fields
- read Google Calendar exports for the production schedule
- audit all supported shows for mismatches, missing assets, and readiness gaps
- generate an Operations Manager dashboard
- generate a Daily Operations Brief
- produce an Operations Copilot work queue
- classify findings with a Trust Layer
- store safe operational learning through Knowledge Mode
- verify whether locally claimed completed work is actually reflected in source data

## What It Does Not Do Yet

Today it does not:

- automatically update HighLevel
- automatically edit Google Calendar
- automatically send Gmail messages
- automatically create or update LinkedIn Events
- automatically change StreamYard
- automatically move or create files in Google Drive

That is intentional. Version 1 is designed to stay read-only while the operating model becomes more reliable.

## How It Will Eventually Support Safe Automation

Over time, this project can support safer automation by:

- learning repeated patterns first
- requiring approval before risky actions
- separating discovery from decision-making
- keeping rules in configuration
- preserving evidence, confidence, and human review boundaries

The long-term goal is not blind automation. The goal is trustworthy operations assistance for Reveting’s LinkedIn Live, podcast, and livestream production workflows.
