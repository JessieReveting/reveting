# Reveting Operations QC Checklist

Use this checklist for local operations flow output, skill updates, and any GitHub process-improvement changes.

## Inputs

- [ ] New bookings checked in `app.reveting.com`.
- [ ] Appointment List View reviewed and Contacts sorted by Last Activity when needed.
- [ ] Booking notification email checked.
- [ ] Total Deliverables Document checked for timezone, channel stack, outline link, show structure, duration, and pre-show time.
- [ ] `ww@reveting.com` event exists; if missing, management notified and manual event created.

## Guest Fit

- [ ] LinkedIn profile URL present and reviewed.
- [ ] Follower count captured.
- [ ] 5,000+ followers accepted as preferred fit, or 1,000-4,999 confirmed with Production + Marketing Lead.
- [ ] Below 1,000 followers rejected unless no better option exists.
- [ ] Guest topics reviewed for show-strategy alignment.
- [ ] Raw submitted topics are not used in guest-facing email or calendar copy.
- [ ] Required event fields are complete before promotion.

## New Booking Calendar Description

- [ ] Event name is `[SHOW NAME] with [GUEST NAME]`.
- [ ] Location says StreamYard URL TBD when link is not ready.
- [ ] Description explains topics will be formatted and emailed later.
- [ ] LinkedIn invite/speaker-role expectation is included.
- [ ] Channel stack placeholder matches Total Deliverables Document.
- [ ] Pre-show and go-live timing are included.
- [ ] Support contact is included.
- [ ] Original guest submission is preserved at the bottom.
- [ ] Date and time are triple-checked in Eastern Time unless show source of truth says otherwise.

## Published Calendar Description

- [ ] Production + Marketing Lead has posted event and finalized title/topics.
- [ ] StreamYard login URL is included.
- [ ] Guest LinkedIn URL is included.
- [ ] Final episode title is included.
- [ ] Topics are edited/final, not raw submissions.
- [ ] Script/client outline link is included where applicable.
- [ ] All active promo links are included.
- [ ] LinkedIn invite walkthrough and 1,000-invite reminder are included.
- [ ] Stream-to-your-audience instructions are included.
- [ ] Original guest submission remains at the bottom.

## Email Cadence

- [ ] T-14 activation email sent 10-14 days before show or immediately if inside 14 days.
- [ ] Published-event email sent once social event links are live.
- [ ] One-week email sent 5-7 days before livestream.
- [ ] Day-before email includes pre-show time, all required time zones, StreamYard link, and what to bring.
- [ ] Day-of email sent morning of or 2-4 hours before pre-show.
- [ ] Post-show email sent within 1 hour or less.
- [ ] Final post-production email sent 24-36 hours after show and never later than 36 hours.

## Post-Production

- [ ] AI clip link included when available.
- [ ] Full recording link included.
- [ ] Transcript link included.
- [ ] Organized Google Drive link included.
- [ ] Human-edited clips delivered or status confirmed.
- [ ] Spotify and Apple links included when uploaded.
- [ ] CTA to share/tag is included.
- [ ] KPI timing recorded by Production Assistant.

## Repo/Automation QC

- [ ] No real API tokens or credentials are committed.
- [ ] Raw SOP extracts with contact details stay local and ignored from Git.
- [ ] Local dry run uses parsed guest/show/date values.
- [ ] Validators run successfully.
- [ ] Any process update is checked against this SOP memory before committing.
